Senior Capstone Project - Project Pedestrian

A partnered capstone project where we researched, designed, and constructed a solution to an open-ended engineering problem involving pedestrian safety. The final product included a Bluetooth sensor at a 4-way intersection, with pedestrians being notified of high traffic density via an iOS app that differentiates between pedestrians and vehicles based on the velocity of the object that stores the Bluetooth signal being transmitted.

This repository is the iOS app portion of the project. The purpose of the app is to have a traffic population map to allow pedestrian users to be aware of when they would be safe at a crosswalk. The app features a map API and notifications that let users know whenever they are approaching a crowded crosswalk.

Notifications were briefly added, but not yet fully implemented.
